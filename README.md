# CLI To-Do List

Uma aplicação interativa de linha de comando (CLI) para gerenciamento de tarefas diárias em memória. Projeto desenvolvido como introdução prática à sintaxe do Python, controle de fluxo e manipulação de estruturas de dados.

## Requisitos

* Python 3.10+
* [Poetry](https://python-poetry.org/) (Gerenciador de dependências e ambientes virtuais)

## Como Executar

1. Clone o repositório:
   `git clone <sua-url-do-repositorio>`
2. Navegue até o diretório:
   `cd <nome-do-diretorio>`
3. Instale o ambiente (se houver dependências futuras) e execute o projeto:
   `poetry run python main.py`

## Funcionalidades

* Adicionar novas tarefas.
* Listar todas as tarefas com seus respectivos status (Pendente/Concluída).
* Marcar uma tarefa como concluída.
* Remover tarefas da lista.
